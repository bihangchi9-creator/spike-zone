# 航驰星野：首轮实施记录

2026-09-19。对应已确认的连续体验与样板星系方案，仅本地修改。

## 本轮结果

- Scene 与 Flight 持续挂载，共享天空、光照和后处理。首页滚动镜头在探索期间停止写入相机；转场与飞行由 Flight 接管，完成事件交接，移除了两个 650ms 定时切换。
- 普通入场时间轴约 4.5 秒：拉远肖像、柔和消隐胸像下缘、显现飞船、稳定到背后视角。飞船使用固定模型尺寸，以位置和透明度进入；返回约 2 秒，并恢复首页 FOV、滚动和入口焦点。转场可取消。
- 星云主要密度频率与包络宽度固定，模式切换不再重塑整体云形。字节方向增加固定的蓝色新月云脊；项目几何按同一转场进度渐现。
- 字节星系向深处移动，五颗项目星体使用独立位置、大小和前后分组。其余星系拉开方位，仍保留原有基本美术；星尘缩小，避免抢占主景。
- 飞船压低机身和驾驶舱，改用较粗糙的蓝灰材质，转弯滚转缓动，尾焰面积收敛。仍为程序模型，未下载或重建精模。
- 星图加入全部项目的直接阅读目录；物料生成 Agent 增加明确标注的方法示意，未新增业务成果数字。已读记录改称“已查看”，保留现有存档。
- 阅读时停船并结束自动领航，关闭后等待输入；从星图切换文章时重置阅读滚动位置。领航抵达后朝向该星系的第一颗项目星体。
- 标签统一在屏幕空间排序与避让：桌面最多三个，手机最多一个。窄屏增加明确启航按钮，触控目标扩大，手机隐藏键盘提示和键盘操作表。保留中英文切换。
- 设置增加“减少动态”，与系统偏好共同作用于云气、星光、星体、星系、收集物和飞船效果；缩短转场、关闭自动项目环绕和加速视角扩张。轻量画质继续保留完整内容。

## 验证边界与后续

本轮没有真实手机 GPU、帧时间和完整手动驾驶测试，不能据此宣称达到方案中的 p95 性能目标；390×844 只是布局模拟。转场做了实际首尾及部分中间画面检查，尚未完成逐帧录屏评审。支线保留，未逐项重新完成收集、穿环与隐藏发现。

新月云脊为有流动纹理、深度测试的局部几何代理，主背景仍是已有动态密度场；这不等同于任意飞行角度下完整的三维体积云。完整近景云深度融合、其他四个星系的独特美术、飞船精模仍属于后续阶段。首轮优先交付可体验的连续样板，不把这些后续目标标成完成。
