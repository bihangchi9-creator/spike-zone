# 航驰星野：入口、探索艇、动态星系整轮验收

本轮在既有个人网站上完成三部分统一升级，保留向下履历/作品、双语、星图与项目直接阅读。未提交、推送或部署。

## 已完成

- 首屏：桌面 5 颗、手机 3 颗体积小星体，约 11–14 秒错峰汇聚到实际入口旁，避开按钮文字；随窗口和语言布局更新，离开首屏停止绘制。减弱动态时静态呈现。
- 探索艇：原创厚实主舱、紧凑推进侧舱、深蓝灰与暖陶瓷材质、侧置探测器、背部格纹标识。后方、前侧、侧面和驾驶方向均已检查。模型 GLB 为 93660 字节、7 个材质组；可编辑 TypeScript 与导出脚本保留。
- 转场：先展示侧后轮廓再接驾驶镜头；跳过按钮、再次进入缩短、减少动态简化过渡。保留胸像下缘淡出。
- 世界：三颗样板拥有气态云带、岩质坑缘/卫星、倾斜星环/碎片。所有项目星体使用不同相位的有限弧线运行和自转。字节星系调近抵达点，扩大气态行星，加入破碎近景云隙；远程领航提高至 42 模拟单位/秒，近处减速。
- 一致性：渲染、距离、碰撞、观察镜头、标签与点击使用同一实时坐标。阅读暂停轨道与自转，关闭后续接。补充标签遮挡，修复星系名被挤成竖排的宽度问题。
- 适配：修复缩放到手机宽度后人物仍使用桌面镜头的旧问题；轻量、减少动态、后台暂停与超采样自动降级。

## 实际验证

通过“首页 → 入场 → 导航至字节星系 → 接近移动岩质项目 → 阅读 → 中英切换 → 继续飞行 → 星图 → 待补充项目 → 返回主页”。在实际运行中顺路收集到一颗星尘。未人为清空原有本机进度。

阅读时观测：轨道时钟固定 75.85 秒，样板坐标固定 [-35.48,35.99,-190.72]；多次读取和中英切换后均保持不变。关闭后继续到 75.90 秒，没有按阅读时长追赶跳跃。390×844 的英文星图：文档宽度、弹窗宽度均为 390，无横向溢出；长大学名称与待补充项目可读。减少动态与轻量设置均通过实际界面开启检查。

- 类型检查通过。
- 11 项回归测试通过：原 8 项，加轨道半径与初始位置、帧率无关时钟/暂停/后台限幅、入口循环衔接与减速。
- Lint 零错误，保留原 SocialIcons.tsx Fast Refresh 提示。

## 性能观察

设备环境：本机 macOS（Darwin）arm64，Codex 内置 Chromium；没有可靠读取具体芯片/GPU型号。以下是开发预览的真实帧间隔统计，不是 GPU 计时，也不是手机真机测试。

同一 1280×800 窗口、DPR 1、精细画质、一次只运行一个 3D 页面，Canvas 截图保留缓冲开启；预热后统计最近 1800 帧，比较字节星系停靠场景：

| 版本 | 平均帧率 | 95% 帧间隔 |
| --- | --- | --- |
| 修改前 | 52 fps | 25 ms |
| 修改后 | 约 50–55 fps | 25–29 ms |

相机停靠点、星体大小与运动不同，单次观测存在波动，不能据此宣称严格性能提升。可以判断本轮测试条件下没有出现明显持续退化。390×844、DPR 1 的轻量/减少动态组合约 120 fps，是同一台 Mac 的窄屏测试，不能外推为手机表现。
