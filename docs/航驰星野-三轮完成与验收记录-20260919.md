# 航驰星野：三轮完成与本地验收记录

日期：2026-09-19。仅本地修改，未提交、推送或部署。

## 第一轮：电影感与连贯体验

延续肖像与飞行共用动态星云、连续镜头和原有向下浏览。统一行星主光方向，降低大气辉光，柔化局部云脊。星环改用归一化径向条带、细节抗锯齿、边缘渐隐和一道暗隙，减少密集同心线的摩尔纹与塑料感。修复远距离直接阅读项目时相机目标被临时变量覆盖的问题。

## 第二轮：星系与飞船

五段经历保留为五个星系，项目为星体：字节跳动的新月云脊、开源的双流星桥、现代汽车的弧湾、崇振的多层云带、大连理工的安静星群。分别调整星体布局、种类和星环。

飞船采用本地程序化建模：收尖船体、后掠翼、座舱、双推进器、翼尖识别灯和随航速变化的尾焰。本轮未下载安装 Blender，也未替换个人肖像模型。局部云带是轻量几何体与透明着色器，主背景保留三维密度场光线步进；不将局部云带称为完整体积模拟。

## 第三轮：星图、阅读与适配

使用内置 image_gen 生成蓝色电影感星图底图，网页使用约 576 KiB JPEG。完整提示词、模式和原图位置记录在 web/public/textures/atlas/ASSET.md。

M 键现在可开关星图。叠加实时星系按钮、中英标签、到访状态、项目清单、实际飞行距离、航线显隐、缩放和自动导航。底图是叙事示意图，不是现实天文图，也不是飞船坐标的等比例投影；界面标注“叙事星图 · 方位示意”。项目可直接阅读，不要求完成挑战。项目页新增“返回星图”和“继续飞行”。两颗缺少材料的星体仍明确标为待补充，不计入八个真实项目的阅读完成数。

星云参考图由运行时加载 8.9 MiB PNG 改为约 848 KiB JPEG，最长边 2048；原图保留。轻量模式现在也将渲染 DPR 限制为 1。默认页面没有性能面板；?diagnostics=1 可用于本地观察帧间隔，不能替代 GPU 分析或真机测试。
