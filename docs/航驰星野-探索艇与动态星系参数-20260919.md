# 探索艇与动态星系：可调参数

## 入口

`web/src/universe/experienceConfig.ts` 集中控制数量与时长：桌面 5 颗、窄屏 3 颗，周期约 11–14 秒，错峰循环、终点减速。`EntryConstellation.tsx` 从真实按钮边界读取汇聚位置，沿右侧留白移动。减弱动态时保留静态构图；离开首屏、进入飞行或页面隐藏时停止入口运动。装饰没有点击事件。

## 镜头与领航

首次入场 5.2 秒，同一会话再次进入 1.4 秒，减少动态为 0.28 秒；始终提供跳过入口。人物淡出、侧后方展示探索艇、镜头落位共用原场景与光照。返回 2 秒。

字节星系抵达点为中心加 [8,13,55]，相对于旧版更靠近项目星体。近处岩质星体、后方大型云带星体和远处稀疏星系共同构成尺度层次。航速上限：近程导航 32、远程 42 模拟单位/秒，接近时自动减速。大尺度气态行星对应真实的“内容审核 Agent 模型迁移调优”项目，可直接阅读。

## 运动与交互

`experienceConfig.ts` 的 `orbitPosition` 是有限弧线运行，不是精确天体力学模拟。初始位置保持设计布局，水平轨道半径不变，扫角上限由 0.2 控制，频率 0.032。各星体初相不同，自转约 0.025–0.053 弧度/秒。

`worldMotion.ts` 维护唯一实时位置与共享时钟。Universe、WorldLabels、Flight 的渲染、遮挡、点击目标、距离、碰撞、观察镜头均引用同一份位置。项目和面板打开、减少动态、页面隐藏时停止轨道与自转；恢复后继续，不追赶暂停时间。卫星和碎片是依附项目星体的环境装饰，不增加项目或游戏门槛，也不设置额外碰撞体。

样板：物料生成 Agent（岩质地貌和卫星）；模型迁移调优（大尺度气态云带与环）；AI 音乐壁纸（倾斜环和碎片）。形象是叙事设计，不暗示任何项目科学属性或额外业务成果。待补充项目仍明确标注。

## 模型

源文件 `web/src/universe/vesselModel.ts`，导出脚本 `blender/explorer/export.mjs`，资产 `web/public/models/explorer/spike-explorer.glb`。原创程序化几何，7 个材质组，93660 字节。可以重跑脚本，也可以将 GLB 导入 Blender 编辑；不声称存在 .blend 源文件。

帽子格纹转化为背部小面积方格板，保留一个个人标识。船首为 -Z。深蓝灰涂层、暖陶瓷板、深色玻璃、裸露金属和舱内暖光分材质。尾焰独立渲染，随航速与加速状态变化。建模截面、推进器位置、设备与面板都可在源文件修改。

## 本地验证工具

`?vessel=side|front|rear|pilot`：四个模型检查视角，仅开发环境。
`?diagnostics=1`：帧间隔、实际窗口、DPR、轨道时钟与样板位置；仅用于观察，不能等同 GPU 耗时。
`?capture=1&label=...`：保存 Canvas 图像、录制 30 秒 3D 画面。它不录制网页 HTML 文字与按钮。媒体只写入本地交付物目录，未纳入生产静态资源。

`web/qa/artifacts.mjs` 为 Vite 开发中间件，生产构建无上传接口。图片、视频和对照页保存在 `交付物/explorer-upgrade-20260920/`。

## 本轮检查中追加的修正

人物镜头现在监听窄屏与触屏条件变化，修复从桌面缩到手机宽度后仍使用桌面构图的问题。星体标签加入实时遮挡检测，不再穿透前景行星。`RenderBudget.tsx` 在预热后观察连续三秒帧间隔，持续低于约 37 fps 时逐级降低超采样 DPR，最低为 1；不减少项目、模型结构或交互。
