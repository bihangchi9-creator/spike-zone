把内容包装中的重复劳动，抽象为可复用的生成式 Agent。

商业增长团队需要频繁把结项素材包装成标准化的案例与宣传物料。传统流程依赖人工梳理素材、组织叙事、选模板、回填内容并校验版式，耗时且质量不稳定；而让通用 Agent 自由生成，又容易信息失真、版式混乱。

我独立完成了整套方案，把这条业务流程拆为「素材处理 → 案例叙事 → 模板回填 → 质量校验」四个可复用的 Skill，再通过 Harness 组装成业务可直接使用的垂类 Agent。架构上，把模型负责的**内容语义判断**，与负责格式、版式、来源校验的**确定性代码**分离，并对关键指标做来源分级、设置人工确认门。

项目形成了显著的工时节省，并沉淀出一条「业务 SOP → Skill → Harness → 垂类 Agent」的通用产品化路径。
