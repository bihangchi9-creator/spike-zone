# 崇振悬浮小镇 · v3 可编辑源（当前 v3.2 悬浮水湾）

2026-09-23，按用户已确认的悬浮与中央池起降概念图建模。2026-09-24 根据用户反馈打开前方池沿，将水面连到太空外缘；v3.2 继续加入两侧发生器与水缘悬浮场。本地版本，待用户验收；未提交、推送或部署。

## 源文件

- `web/src/universe/worlds/builders/harborRefinedV3.ts`：全部实体几何，独立于保留的 v1/v2。
- `blender/harbor-refined/export-v3.mjs`：导出精细和轻量 GLB，原子写入，保留材质名称，量化无需远程解码器。
- `blender/harbor-refined/textures-v2.py`：继续复用 v2 的 23 张材质图，不重复添加纹理包。
- `web/src/universe/worlds/HarborRefined.tsx`：版本选择、PBR/透射材质、环境图、室内局部光。
- `web/src/universe/worlds/HarborTechnology.tsx`：动力舱与船底短推进光、水面光纹、局部照明和起降展示。该文件与 GLB 共同组成网页效果。
- `web/src/universe/worlds/HarborWaterField.tsx`：水缘约束光、流动纹理和六颗悬停水滴，与小镇共用暂停时钟。
- `web/src/universe/worlds/harborTechnologyConfig.ts`：起降轨迹与动力舱光源锚点。

本轮为可编辑的 Three.js 参数化建模，不是 Blender 手工雕刻。没有 `.blend` 成品。GLB 可导入 Blender，但几何已按材质合批，需重新连接外部纹理。保留独立建筑、动力系统、两艘工作艇和灵感艇顶层组；具体物件的编辑在 TypeScript 源中进行。网页文字由原有 `WorldSigns` 生成。

## 重建

先在 `web/` 安装前端依赖，在 `blender/harbor-refined/` 安装相邻 `package.json` 的建模工具依赖（当前机器复用已有本地同版本工具）。从仓库根目录运行：

```sh
node blender/harbor-refined/export-v3.mjs
```

贴图无需重建；需要修改表面时再按 `README.md` 中说明执行 `textures-v2.py`。前端检查在 `web/` 运行：

```sh
npm test
npm run lint
npm run build
npm run dev
```

## 本轮几何

五组动力舱分别有安装法兰、承重耳、装甲分瓣、检修窗、散热槽、陶瓷隔离圈、喷口空腔、发光芯与导向片。底部为金属腹部、横纵梁、检修底板、散热结构和连接管线；前沿下半部改成机械服务带。v3.1 将前方闭合池沿改成两侧码头围合的开放水湾，水面延伸至外缘，前段池底渐浅；基座开槽、管线退至两侧，原前方中央动力舱移到腹部。v3.2 在两侧码头安装带支架、供能线、陶瓷隔离筒与光学透镜的场发生器；前段池底和金属底板向后收约 0.42 单位，使最后一段水面伸出实体支撑。石砌上部、房屋数量和工作空间保持。

灵感艇改到中央池上方并放大至原型 1.25 倍，增加四个支撑明确的升力组件、后驱动舱和座舱仪表；两艘工作艇移向池边。增加有实体支撑的屋顶接收天线、通信设备、桌面投影器和池边充能终端。设备与图稿属于场景艺术表达，未新增真实项目声称。

## 起降与暂停

48 秒局部展示循环：先悬停，7 秒后开始上升，12–18 秒沿开放水湾出港，18–22 秒在前方转向，22–29 秒回航，29–34 秒降回池中，其余时间静止等待。它是小镇局部的出港回航演示，尚未开发跨星球送达与任务系统。

轨迹保留在原世界的飞行避让范围内；先升高，再沿前方开口出港。模型检查页默认静止以便对照，可点击“播放起降演示”。正式查看组件中按现有动态选项运行；阅读项目、减少动态、后台隐藏时暂停，不按墙上时钟补跑。远处模型保持中央悬停姿态。
