# Hyundai 蓝白微缩主星球 v3（本地试点）

本模型只替换现代汽车经历，其他星球未重构。原始概念见 `交付物/现代汽车紫色工厂星球-20260920-v1/现代汽车-蓝白一体化座舱-v3.png`。

## 可编辑来源 / 重新导出

- 几何源：`web/src/universe/hyundai/model.ts`。真实 Three.js 几何，非概念图贴片。
- 在仓库根目录运行 `node blender/hyundai/export.mjs`；依赖使用 web 已安装的 Three.js / TypeScript。
- 输出：`web/public/models/hyundai/hyundai-world.glb`。3,301,396 字节、28 个 mesh、45,572 个三角形。可导入 Blender 继续编辑；本轮没有创建 .blend 文件。
- GLB 按材质合并静态几何，保留两辆测试车、四个机械臂的独立节点。仅座椅、车辆和大内饰件保留高分段圆角。
- 玻璃外壳、真实标志贴图和音乐屏幕由 `HyundaiWorld.tsx` 叠加。导入 GLB 到其他软件时需另外重建这三项；完整网页场景来源是 GLB + 该组件。

## 结构与材质

上半部：四跨折线采光顶、玻璃工厂立面、装配车/机器人、连续环形道路、安全栏杆、两辆运行车辆、圆形展示亭、后门和检修楼梯。

下半部：半球玻璃、三条连续白色支撑肋、细金属分格、两张浅色座椅、弧形围壁、方向盘、中控台和蓝白音乐波形屏幕。外壳采用低透明度 Fresnel 边缘与分开绘制的前后面，不使用昂贵的真实多次折射，也不伪称物理玻璃模拟。结构内部写深度；玻璃关闭深度写入。

材质基础色 Hyundai Blue #002C5F、White #FFFFFF。灯光和色调映射会改变最终屏幕像素。采用暖色小灯，机器人为克制的暖黄色。

## 尺寸与接入

模型局部半径约 10.2，世界缩放 2.65；保守碰撞球半径 29（旧项目球 8.6）。位置由现有实时世界坐标提供，旋转速度 .004 rad/s。`pose.ts` 统一停靠及舱内锚点；导航目标跟随星球旋转，碰撞半径测试覆盖导出后全部顶点。

`Universe.tsx` 仅对 `ai-music-wallpaper` 加载现代组件，停用现代旧云弧/紫色地标。`Flight.tsx` 使用旋转停靠点和座舱阅读镜头，窄屏增加现代附近的观察距离。`WorldLabels.tsx` 把项目入口放在下半舱。`StarAtlas.tsx` 改为蓝白座舱主星和座舱项目分类。

世界时钟暂停时，旋转、道路车辆、机械臂及屏幕全部暂停，恢复后继续。低画质减少玻璃分段并隐藏第二辆测试车。用户探索记录不清空。

## 事实边界

工厂和道路是经历的视觉主题。实际履历仍只描述智能座舱产品实习及 AI 音乐壁纸；未添加制造/生产经历。此资产是三维原型试点，车辆、机器人、园林及内饰细节为程序化简化，未达到批准概念图的摄影级质感。
